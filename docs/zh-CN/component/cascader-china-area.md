# Cascader-China-Area 中国城市联级选择器

这是一个对 Cascader 级联选择器的简单封装，仅仅是加了中国城市（省市区三级）数据，使用方法与联级选择器一致

唯一的区别就是，千万不要给 options 属性传入数据，否则数据就被覆盖了。

## 基础用法

::: demo

cascader-china-area/basic

:::

其他功能请参阅 [Cascader](https://element.eleme.cn/#/zh-CN/component/cascader)
