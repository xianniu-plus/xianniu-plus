# Cascader-China-Area

This is a simple wrapper for the Cascader component, which only adds Chinese city (province-city-district three levels) data. The usage is consistent with the Cascader component.

The only difference is that you should never pass data to the options property, otherwise the data will be overwritten.

## Basic Usage

:::demo

cascader-china-area/basic

:::

For other features, please refer to [Cascader](https://element.eleme.cn/#/zh-CN/component/cascader)
